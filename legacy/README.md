# Legacy (v4)

This folder holds the v4 code of `panneau-js`, as it was on the `v4.0` branch when `v5.x` started. It is outside the npm workspaces: nothing here is built, linted, tested or published from `v5.x`.

It is kept as a reference while components are ported to the v5 packages in `packages/`. Ported code is deleted from here in the same pull request, and the folder is deleted before 5.0.0. See [`docs/decisions/0018-new-packages-next-to-v4.md`](../docs/decisions/0018-new-packages-next-to-v4.md).

v4 is maintained on the `v4.0` branch.
