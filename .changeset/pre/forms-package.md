Add `@panneau/forms`: `Form` (from fields and an `onSubmit`, with or without a definition) and `FormView` (for a form state made with `useForm()`), which render the form state of `@panneau/core`. Layout with rows, columns, collapsible sections, tabs, a sidebar and `visibleWhen`; errors next to fields, in a summary, counted on tabs and sections, with a scroll to the first one; network errors with a retry; unsaved changes guards; an error boundary per field; and the version conflict dialog. Rule messages and the UI are in English and French.
