# Panneau

React packages for admin panels and content management, published as `@panneau/*`. [`laravel-panneau`](https://github.com/folkloreinc/laravel-panneau) is the reference backend.

## Versions

| Version | Branch | React      | Status                                                                                                 |
| ------- | ------ | ---------- | ------------------------------------------------------------------------------------------------------ |
| 5.x     | `v5.x` | 19.2+      | In development ([roadmap](https://github.com/folkloreinc/panneau-js/issues/6), [docs](docs/README.md)) |
| 4.x     | `v4.0` | 19.2+      | Maintenance                                                                                            |
| 3.x     | `v3.0` | 16.8 to 19 | Maintenance                                                                                            |

## Development

```bash
npm install
npm test
npm run lint
npm run typecheck
npm run build
```
